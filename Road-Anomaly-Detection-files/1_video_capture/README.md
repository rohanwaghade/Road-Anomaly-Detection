
# Video Capture using GPS Map Camera App

To collect road video data with GPS coordinates, we recommend using the **GPS Map Camera** app.

## 📱 App Installation

- **Android:** [GPS Map Camera on Google Play](https://play.google.com/store/apps/details?id=com.gpsmapcam.mapstampcamera)
- **iOS:** [GPS Map Camera on App Store](https://apps.apple.com/us/app/gps-map-camera-geo-location/id1502634997)

## 📸 How to Use the App

1. **Install the app** from the links above.
2. Open the app and allow permissions (Camera, Location, Storage).
3. Configure the stamp settings:
   - Enable GPS coordinates
   - Enable date & time
   - Set stamp position (bottom, center, etc.)
4. Start recording the road while mounting your phone on a dashboard or helmet.
5. Videos will be saved in your gallery with embedded GPS info.
6. Transfer videos to your computer for further processing.

## 📝 Notes

- Make sure GPS is turned ON and has good signal while recording.
- Keep the phone stable to avoid shaky videos.
- Prefer daylight for better model training.
